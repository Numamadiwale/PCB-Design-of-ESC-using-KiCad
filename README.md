# PCB-Design-of-ESC-using-KiCad
PCB Reverse Engineered Design of an ESC using Kicad ver 9.0
This design is Reverse Engineered design of hakrc 4255 120a single ESC however this design isnt a 100% recreation of the original Design and liberties were taken while designing the device. the design is yet to be Validated by a seasoned PCB designer before it can be considered for production

The Design had no DRC Errors but had floating island warnings , take this into strict considerations before attempting anything. Design optimization i highly needed to further minimize the size of the board
